# Manorath Khanna - portfolio

A simple static portfolio website hosted with GitHub Pages.

## Publish with GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the main branch and **/ (root)** folder, then save.
4. GitHub will show the published site address in the Pages section when deployment is ready.

The page includes contact details from the resume and is publicly visible.
